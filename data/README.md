# 研究數值與差異對照

[research-audit.json](research-audit.json) 保存少量已發表的 Table 2 數值及歷史簡報對照，目的為追溯，沒有企業層級原始資料。

- `hypothesis_specific_models` 的五列分別來自 M2–M6，不是同一個完整模型。
- `.000` 是原表顯示的四捨五入結果，公開敘述改為 `< .001`。
- `selected_full_model_caveats` 明列未達 5% 門檻的選定效果，不能視為全部模型清單。
- `relocation_conflict` 保存兩份課程材料的說法差異，不代表任何比例已獲確認。

原研究、版本與頁碼見 [來源表](../docs/sources.md)，統計解讀見 [研究審閱](../docs/research-review.zh-TW.md)。
